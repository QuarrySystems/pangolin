# @quarry-systems/pangolin-product

Consumer-side read of a dispatch's product — the output sentinel and its
content-addressed artifacts. Depends only on `@quarry-systems/pangolin-core`,
following the `pangolin-verify` precedent of keeping core dependency-light.

```bash
pnpm add @quarry-systems/pangolin-product
```

Part of [pangolin](https://quarrysystems.github.io/pangolin).
